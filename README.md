# bonaVITA Info-TV

- `training/` – Info-TV Trainingsbereich
- `physio/` – Info-TV Physio-Wartebereich

Jeder Ordner ist eine eigene Netlify-Site (Base directory = Ordnername, kein Build-Befehl, Publish directory = Ordnername).
Einstellungen (Öffnungszeiten, Massage, Aktionsfolien) stehen oben in der `index.html` im Block `CONFIG`.
